02 / BINDINGS

Controls and remaps

Choose a Minecraft control by its default key and action. Defaults are for Minecraft Java 1.16, even if your instance uses different bindings. Use Record input, then press a key or mouse button within five seconds. Recording stops after the first complete binding; waiting keeps the old value. You can also enter key names manually. Side buttons depend on browser support. Mouse recording is available for Minecraft controls and emitted bindings. Mouse triggers for crafting, Ninjabrain, and chat require explicit keyd mouse-device setup; record keyboard keys in those fields.

03 / CHAT

Chat keys

These keys enter or leave the pass-through chat layer. Keep them distinct from controls and remap sources.

04 / WINDOW

Resize presets

Up to eight presets. Record a keyboard shortcut by holding modifiers and pressing a key. Mouse buttons are unavailable for resize shortcuts. One preset can use eye zoom sensitivity when maccel is available.

05 / REVIEW

Preview and apply

Save the profile, then preview the exact physical → emitted → Minecraft action mapping for each instance. Changes to the form clear the preview.

06 / RECOVERY

Restore a backup

A successful Apply can return a backup ID. Restore returns toolkit-managed files to that saved state.
